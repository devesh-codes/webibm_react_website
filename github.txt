initialize git into project
		git init 

check status
		git status

add file (stagging)

		git add .

	fileName for specific file

show current branch

  		git branch

		git branch branchName

		git switch branchName

		git switch -c branchName

		git checkout branchName



-------------------------------------------

merge branch
	note-: firstly you have switch on the branch before merging

		git merge branchName
